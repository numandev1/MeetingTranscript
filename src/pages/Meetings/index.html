Integrate TranscripTonic with your favourite tools

You can connect TranscripTonic directly to any tool that supports webhooks. If it does not, you can use automation tools like n8n as a bridge.

Your name

Captions label your own speech as You. Set your name here and it is written into transcripts, webhooks and Obsidian notes instead. Google Meet can detect this on its own, but Teams and Zoom cannot — so leaving it empty means those transcripts keep saying You.

Webhook body (simple)

    "webhookBodyType": "simple",
    "meetingSoftware": "Google Meet",

    "meetingStartTimestamp": "01/15/2024, 10:00 AM",
    "meetingEndTimestamp": "01/15/2024, 11:00 AM",

Save to Obsidian

Saves every meeting as a note in your vault, alongside the text file. Requires the Local REST API community plugin, with its non-encrypted (HTTP) server enabled — the HTTPS port uses a self-signed certificate that browser extensions cannot accept.

Copy it from Obsidian → Settings → Local REST API. Stored on this device only, and never synced to your Google account.

Folder inside your vault, created automatically. Leave it empty to save notes at the vault root. Each note is named Meeting title 2026-09-14.
